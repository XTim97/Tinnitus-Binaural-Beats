# Tinnitus Binaural Beats

A cross-platform Progressive Web App for iPhone, iPad, Android, tablets, Windows, and Mac browsers.

## GitHub Pages publishing

1. Create a new GitHub repository named `tinnitus-binaural-beats`.
2. Upload all files and folders from this project to the repository.
3. Commit them to the `main` branch.
4. In GitHub, open **Settings > Pages**.
5. Under **Build and deployment**, set **Source** to **GitHub Actions**.
6. Open the **Actions** tab and wait for the `Deploy to GitHub Pages` workflow to finish successfully.
7. GitHub will show the published Pages address.

## Install on a device

### iPhone / iPad
Open the published site in Safari, tap **Share**, then **Add to Home Screen**.

### Android
Open the published site in Chrome and choose **Install app** or **Add to Home screen**.

## Safety note

This app is intended for low-volume relaxation and sound experimentation only. Binaural beats are not an established treatment for tinnitus. Keep headphone volume comfortable and stop if symptoms worsen.
